## چطور اجرا کنم؟

**ساده‌ترین راه: Colab.** روی دکمه‌ی «Open in Colab» فصل موردنظر کلیک کنید. به نصب چیزی نیاز ندارید.

**روی کامپیوتر خودتان:**

```bash
git clone https://github.com/Alireza-Akhavan/ThinkPython.git
cd ThinkPython
pip install -r requirements.txt
jupyter lab chapters_fa/chap01_fa.ipynb
```

نکته‌ها:

- سلول اول هر نوت‌بوک (بعد از عنوان) را **اول از همه اجرا کنید**. این سلول فایل‌های کمکی کتاب (`thinkpython.py`، `diagram.py`، `words.txt` و ...) را از همین مخزن دانلود می‌کند و دستورهای ویژه‌ی `%%expect` و `%%add_method_to` را فعال می‌کند. برای اجرا به اینترنت نیاز دارید.
- نوت‌بوک‌ها با خروجی ذخیره‌شده نیستند، مثل نسخه‌ی اصلی کتاب. با اجرای هر سلول خروجی را می‌بینید.
- سلول‌های تمرین (`# Solution goes here`) را خودتان پر می‌کنید. تا وقتی پر نشده باشند، سلول‌های بعدی که از آن‌ها استفاده می‌کنند خطا می‌دهند. این رفتار نسخه‌ی اصلی هم هست.

## چه چیزی در مخزن هست؟

```
chapters_fa/      نوت‌بوک‌های فارسی (پیشگفتار و فصل‌های ۱ تا ۱۹)
chapters/         نوت‌بوک‌های انگلیسی نویسنده (بدون تغییر)
blank/            نوت‌بوک‌های خالی انگلیسی (برای تمرین)
thinkpython.py, diagram.py, structshape.py, jupyturtle.py
words.txt, pg43.txt, pg345.txt, pg1184.txt, photos.zip    فایل‌های داده‌ی کتاب
ORIGINAL_README.md   README مخزن اصلی
TRANSLATION_NOTES.md یادداشت‌های ترجمه و فهرست تغییرها
tools/               ابزارهای کمکی (تغییر نشانی مخزن)
```

فایل‌های کمکی و داده از مخزن اصلی نویسنده گرفته شده‌اند تا نوت‌بوک‌ها به این مخزن وابسته باشند، نه به شاخه‌ی `v3` مخزن اصلی. فایل `jupyturtle.py` ساخته‌ی Luciano Ramalho است و با مجوز BSD-3 در [مخزن خودش](https://github.com/ramalho/jupyturtle) منتشر شده.
